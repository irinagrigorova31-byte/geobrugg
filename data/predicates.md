## Пустоты (высокий потенциал отстройки, у конкурентов слабо/нет)
- **Класс энергии барьера в кДж как критерий подбора** — только у нас явно (3000/10000). Конкуренты пишут «барьеры» без энергетики. Сильная извлекаемая отстройка.
- **Марка стали >1770 Н/мм² + покрытие Zn/Al (×5 срока)** — конкуренты пишут «оцинкованная»/«Гальфан ×2–3»; у нас число выше и покрытие лучше — прямое сравнение.
- **Полномасштабные испытания, подтверждённые институтами** — у конкурентов «сертифицировано по нормам РФ» (geobarrier); у нас — испытания + независимая верификация.
- **Локализация в Краснодаре (2016)** — снимает возражение «импортное/санкции», которое geobarrier закрывает лозунгом «создано в России». Нам нужно сказать это явно.
- **Точки отказа** (когда метод не работает) — почти никто не пишет честно; borey частично. Наш блок «границы применимости» = чистая отстройка (I-2а).

## Предикаты «точки отказа» (для генерации отстройки, III-6)
- активная сетка → не работает при → глубоком оползне (только приповерхностные нестабильности)
- поверхностное укрепление → не работает без → дренажа/водоотведения (переувлажнение — корневая причина)
- габионы → не подходят для → 1–2 степени угрозы и размещения у жилья (borey)
- барьер → перестаёт работать при → превышении расчётного класса энергии (кДж)
- подбор системы → невозможен без → инженерно-геологических изысканий
