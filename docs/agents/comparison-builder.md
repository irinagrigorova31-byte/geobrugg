# comparison-builder — конструктор честных сравнений (опциональный)

**Место в конвейере:** опциональный, включается для кластеров с интентом «топ / лучшие / сравнение». Питает архитектора данными для статьи-сравнения.
**Модель:** opus. Честные мульти-рейтинги — суждение.

## Что делает
Когда запрос про «лучшие сервисы» или «сравнение», обычная посадочная не подходит — нужна статья-сравнение. comparison-builder собирает срез «участник × атрибут»: строки — конкуренты плюс наш бренд, столбцы — единый фиксированный набор характеристик. «Нет данных» по участнику остаётся ячейкой, участника не выкидывают. И строит **несколько мини-рейтингов по явным критериям** — по цене, по лицензии, под конкретную задачу, — где лидируют разные участники. Свой бренд идёт на общих правах, с честным ограничением «кому не подходит», искусственно поднимать его нельзя. Умеет подмешивать **реальные отзывы с Яндекс.Бизнеса / Карт** (рейтинг, число отзывов, повторяющиеся похвалы и боли) как источник данных для среза.

## Зачем он нужен
Формулировки «лучшие / №1» без указанного критерия — это и юридический риск, и потеря доверия аудитории. Честное сравнение, где по разным критериям выигрывают разные, читается как экспертиза, а не как самореклама, — и именно это даёт information gain, которого нет у конкурентов.

## Что получает и что отдаёт
Получает: матрицу, данные конкурентов, отзывы (если подключены). Отдаёт: срез сравнения, который архитектор разворачивает в чертёж статьи-сравнения (таблица сверху, самодостаточные блоки по участникам, мини-рейтинги, блок оригинальных данных).

## Петли и ворота
Отдельных петель нет; его срез идёт в архитектора как вход для режима сравнения.

## Коротко
Он собирает честное сравнение с мульти-рейтингами по явным критериям и реальными отзывами — так, чтобы свой бренд стоял на общих правах, а не №1 без причины.
