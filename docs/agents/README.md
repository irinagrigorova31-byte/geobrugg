# Агенты tripl — человеческое объяснение

Здесь по файлу на каждого агента: что делает, где в порядке, зачем — написано для человека, а не как инструкция. Спеки самих агентов (то, что они читают как задание) лежат в `.claude/agents/`; здесь — объяснение «зачем это устроено так».

> Что подаёт на вход **оператор** (в какие файлы и в каком формате) — в `../INPUTS.md`.

## Идея всей системы (в двух абзацах)
Всё существует ради одной задачи — сделать страницу, которую **выберут**: не просто которая ранжируется, а которую поисковик поставит в десятку, а AI-ответ процитирует, хотя цитирует он 3–5 источников. Ключевая мысль: быть хорошим недостаточно — если ты похож на уже выбранный более сильный источник, тебя вытеснят, потому что отбор ценит разнообразие. Значит каждая страница обязана нести то, чего нет у конкурентов.

Отсюда два принципа, объясняющие почти всё: **ничего не выдумывать** (всё — реверсом реальных страниц или из подтверждённых данных клиента) и **кто делает, тот не проверяет** (автор не судит себя — поэтому половина агентов это независимые контролёры).

## Модели, одной мыслью
Где ошибку видно только повторив работу (суждение, архитектура, текст, аудит) — сильный ум (opus). Где результат проверяется процедурой (разметка, вёрстка) — средняя модель (sonnet). Где падение ловит скрипт (гомоглифы) — дешёвая (haiku).
