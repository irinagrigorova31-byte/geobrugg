## Заметки для последующих этапов
- Выгрузка тонкая: реальный топ есть только по «борьба с оползнями» (инфо-доминантный SERP).
- Операторский prompt-set (input/prompts.md, 10 промтов) задаёт целевые кластеры — топ по ним НЕ собран, ушли на дозагрузку (pass-2).
- Обзора ИИ в выгрузке нет ни по одной ПС → neuro-слой и brand-presence по AI-обзору serp-parser посчитать не сможет, пока не появится pass-2 с блоком «Обзор ИИ».
- Пары кластеров с пересечением ≥70% (для этапов 4 и 7): пока не считаются — один собранный кластер.
