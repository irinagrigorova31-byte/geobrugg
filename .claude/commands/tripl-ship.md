Выполни БЛОК 4 пайплайна tripl — оформление и сдача. Аргументы: $ARGUMENTS

Финальный блок. Доводит тексты до файлов в delivery/. Оркеструешь сам.
Hero-обложки — ручной шаг ВНЕ пайплайна: агент даёт бриф, картинку генерит человек
внешне (ChatGPT/DALL·E) и кладёт PNG по путям из брифа.

# Предусловия
1. Прочитай CLAUDE.md.
2. Проверь: есть drafts/ с текстами, прошедшими аудит (review/audit-NN.md со статусом
   готовности) и review/cluster-report.md с вердиктом не «дублирующий массив».
   Нет → ОСТАНОВИСЬ, сначала /tripl-write.
3. Дополни review/run-log.md.

# ЭТАП 8 — оформление (параллельный блок)
ОДНИМ сообщением запусти три агента:
- schema-markup → JSON-LD под H2 `## РАЗМЕТКА` в drafts/page-NN.md + data/triplets.json
  (разметка И JSON матрицы — это один агент).
- infographic-maker → assets/infographics/*.svg + placement-файлы (только инфографика).
- hero-maker → assets/hero/page-NN-prompt.md — БРИФ на hero + og:image (не картинка).
Дождись всех. Проверь: блок `## РАЗМЕТКА` в каждом черновике; placement при наличии SVG;
брифы hero; data/triplets.json валиден (python json.load).

# ЭТАП 9 — page-builder, стадии 1-2 (вёрстка + UX)
Запусти page-builder на каждую страницу (можно параллельно, волнами, файлы не пересекаются).
Стадии: вёрстка HTML (забирает JSON-LD из блока `## РАЗМЕТКА` в `<head>` — блока нет → СТОП,
сам разметку не собирает; путь og:image берёт из брифа hero заранее) → UX-полировка (/impeccable).
Хочешь прогнать `/impeccable polish preview/` сам в основной сессии между волнами — можно;
сабагенту эту команду не передавай.
Выход: preview/page-NN.html. Упаковку (стадия 3) здесь НЕ запускать — она после инспекции.
Расхождения «разметка↔текст» из отчётов — в run-log, закрой через schema-markup/copywriter.

# ЭТАП 10 — final-inspector (цикл, макс 2)
Запусти final-inspector. Выход: review/final-report.md.
- RELEASE → этап 11.
- FIX → по таблице | Проблема | Файл | Ответственный агент | запусти указанных агентов
  (каждому его строки). Правки текстов → точечно gist-auditor по затронутым страницам.
  Затем повторный final-inspector.
  СТОП: после 2-го FIX → ОСТАНОВИСЬ, покажи таблицу владельцу.

# ЭТАП 11 — page-builder, стадия 3 (упаковка) — ТОЛЬКО при RELEASE
Запусти page-builder в режиме упаковки. Выход: delivery/page-NN.html + meta + instructions.
СТОП: остановился на заглушке [ТРЕБУЕТСЯ] — это дыра, которую должен был поймать
final-inspector. Покажи владельцу, не дочищай сам.

# ЭТАП 12 — homoglyph-checker (финальный техчек, ПОСЛЕ упаковки)
Запусти homoglyph-checker — ОТДЕЛЬНЫЙ агент ПОСЛЕ page-builder целиком.
Прогон по preview/ И delivery/ — он видит финал, включая то, что внесла упаковка
(чистка следов, CMS-фрагмент, перекодировка).
Финальная строка review/homoglyph-report.md обязана быть «после проверки чисто».
Не чисто → исправь через него же, повтори. Без неё страница не выдаётся.
