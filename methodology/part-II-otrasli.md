# ЧАСТЬ II. ОТРАСЛЕВЫЕ ПРАВИЛА

Каждое правило — надстройка над Частью I под конкретный тип страницы. Значения-заглушки
заменять реальными; разметка = видимый текст слово в слово.

## II-A. Провайдеры интернета: страница «интернет по адресу»

**Тип:** dom-level/street-level страница агрегатора «подключить интернет по адресу». **Интент:**
локальный коммерческий. **Приоритет:** Яндекс.

**Суть.** Связка «дом (адрес) → провайдеры → тарифы». Главный риск — шаблонные пустые dom-страницы
= дорвей (фильтр Яндекса, восстановление 30 дней – 3 месяца). Каждая страница обязана нести
уникальный смысл (реальные провайдеры/технологии/скорости дома).

**Обязательное ядро триплетов (паритет):**
- адрес → обслуживается → провайдером X | `Service`+`areaServed`=`Place`
- провайдер X → имеет тех.возможность по адресу → да/нет | `Service`
- провайдер X → предлагает → тариф Y | `Product`/`makesOffer`
- тариф Y → имеет скорость → N Мбит/с | `QuantitativeValue`
- тариф Y → имеет абонплату → N руб/мес | `Offer`+`priceSpecification` (RUB, /MONTH)
- тариф Y → тип → интернет / +ТВ / +ТВ+моб / +моб | `category`
- дом/город → содержит → N провайдеров / N тарифов | `ItemList`/`numberOfItems`
- провайдер X → имеет рейтинг → N (M отзывов) | `AggregateRating`+`Review`
- провайдер X → стоимость подключения → N руб | `Offer`

**Отстройка (у единиц):**
- дом → подключён по технологии → GPON/FTTB (на уровне ДОМА) | `Service`+`areaServed`=`Place`
- тариф → включает → роутер/приставку/кинотеатр/SIM | `Offer.addOn`
- оборудование → доступно как → аренда/рассрочка/покупка с ценой | `Offer`
- сервис → даёт гарантию → 90 дней (переподключение + 1-й мес)
- провайдер → покрытие → N адресов / N% района
- беспроводной провайдер → до 300 Мбит/с (fallback для новостроек)

**Сущности:** провайдеры (Ростелеком, МТС, Дом.ру/ЭР-Телеком, Билайн, МегаФон, ТТК, Т2, Акадо,
ОнЛайм и региональные) — федеральные есть в Wikidata; технологии (GPON/FTTB/FTTH/xPON/ADSL/DOCSIS/
Ethernet/оптика); типы (интернет / +ТВ / +моб); атрибуты (скорость, цена, подключение, промо, покрытие).

**Мета/структура:** URL `/город/улица/дом`; Title «Интернет по адресу [улица, дом] в [городе] —
провайдеры и тарифы 2026»; H1 = адрес; H2 = провайдеры/тарифы/технологии/FAQ; абзац-паспорт с числами.

## II-B. Языковая школа китайского: коммерция + инфо

**Тип:** страница курса (коммерция) + карточка преподавателя + инфо-статья. **Приоритет:** Яндекс.
E-E-A-T решает (лицензия, квалификация преподавателей, результаты учеников).

**Двухконтурность:** коммерция (курсы/репетитор/HSK) + инфо (иероглифы/тоны/пиньинь/HSK-справка →
конвертируется в курсы). Инфо-ниша слабо занята профильными игроками.

**Обязательное ядро (курс):**
- курс → готовит к → HSK (1–6/9) | `teaches`, `educationalCredentialAwarded`
- курс → для → с нуля / детей / взрослых | `coursePrerequisites`, `audience`
- курс → формат → онлайн/офлайн/индивидуально/группа | `courseMode`
- курс → стоит → N ₽ | `offers.price`
- курс → длится → N месяцев/занятий | `timeRequired`
- школа → имеет лицензию → № | `hasCredential` (license)
- преподаватель → носитель / имеет HSK 6 | `Person`, `hasCredential`

**Отстройка:** HSK 3.0 vs 2.0 точные слова с датировкой; методика BLCU; оплата маткапиталом/вычет;
гарантия сдачи; результаты учеников с цифрами; CourseInstance с расписанием.

**Сущности:** уровни HSK (2.0: 150/300/600/1200/2500/5000; 3.0: 3 ступени 9 уровней, финал 2025,
HSK1=300 слов; полное внедрение 01.07.2026); HSKK/YCT/BCT; 4 тона+нейтральный; 214 ключей; пиньинь;
путунхуа vs кантонский; форматы; типы курсов. Wikidata: китайский Q7850, путунхуа Q727694, иероглифы
Q8201, пиньинь Q42222, HSK Q1163680, ключ Канси Q719834, кантонский Q9186.

**Разметка:** дублировать JSON-LD (Google/AI) + Microdata/RDFa (Яндекс) + YML-фид. В `Course`
Яндекс запрещает цены/призывы (цены — в Offer/фиде). Числа HSK — всегда с редакцией и датой.

## II-C. Ремонт УЗИ-оборудования (B2B медтехника)

**Тип:** главная сервиса / «ремонт УЗИ [бренд]» / «ремонт датчиков» / страница неисправности /
инфо-статья. **Интент:** B2B коммерческий + информационный. **Приоритет:** Яндекс. Доверие
критично (лицензия ТОМИ, гарантия, оборудование, юрлицо).

**Суть.** Ядро: «сервис → ремонтирует → {аппарат | датчик}», «датчик → имеет элемент → {линза |
кристаллы | кабель | коннектор}», «симптом → указывает на → неисправность узла». Инсайт рынка:
70–80% обращений — датчики (самая уязвимая и дорогая часть). УТП — компонентный ремонт (дешевле
замены платы). Schema.org у конкурентов почти нет — главная точка отстройки.

**Обязательное ядро:**
- сервис → ремонтирует → УЗИ-аппарат / датчик | `Service`
- сервис → обслуживает бренды → GE/Philips/Siemens/Mindray/Samsung Medison/Toshiba-Canon/Hitachi-Aloka/SonoScape/Esaote
- сервис → выполняет → бесплатную диагностику | `Offer.price=0`
- сервис → выполняет → выезд инженера
- сервис → выполняет → компонентный ремонт плат/БП
- ремонт → гарантия → 12 месяцев | `Offer.warranty`
- сервис → заменяет → линзу/кристаллы/кабель/коннектор датчика
- симптом → указывает на → неисправность узла

**Отстройка:** лицензия Росздравнадзора ТОМИ; договор на ТО «для лицензирования клиники»; подменное
оборудование/аренда; конкретный прайс; официальный СЦ бренда; ремонт TEE-датчиков; BGA-пайка;
JSON-LD-граф (которого у конкурентов нет).

**Симптом → неисправность → ремонт (инфо-контур):**
- не включается → БП/предохранитель/плата → ремонт/замена БП
- чёрный экран → монитор/подсветка/видеотракт/БП → ремонт видеотракта
- «снег»/артефакты → beamformer → компонентный ремонт платы
- вертикальная полоса/провал → выпадение (dropout) кристаллов → замена кристаллов
- полосы (сильнее в ЦДК) → повреждение кабеля → ремонт/замена кабеля
- пузыри под линзой → отслоение линзы → замена линзы
- «Probe not supported» → сбой ID/ПО → перепрошивка датчика
- датчик отходит → коннектор (замок/пины) → ремонт коннектора

**Сущности:** бренды и линейки (GE Logiq/Vivid/Voluson, Philips Affiniti/EPIQ, Siemens Acuson,
Mindray, Samsung Medison, Toshiba/Canon Aplio, Hitachi/Aloka Arietta, SonoScape, Esaote MyLab);
типы датчиков (линейный/конвексный/микроконвексный/секторный/матричный/внутриполостной/TEE/3D-4D/
карандашный); элементы (кристаллы/линза/согласующий слой/демпфер/кабель/коннектор); узлы (БП/
матплата/beamformer/монитор/тачскрин/трекбол/HDD); услуги (диагностика/компонентный ремонт/ТО/
поверка/выезд/запчасти); регуляторика (медизделие, РУ, лицензия ТОМИ, класс риска 2б, ГОСТ ISO
13485-2017, ПП №2129).

**Разметка:** `AutoRepair`... нет — `Organization`/`LocalBusiness` (name, legalName, taxID, telephone,
address, areaServed, sameAs, hasCredential) → `Service`+`hasOfferCatalog`→`Offer` (price/warranty) →
`FAQPage` → `BreadcrumbList` → `AggregateRating`+`Review`.

## II-D. Автосервис Mercedes-Benz (специализированный, Москва)

**Тип:** главная / страница модели (W204/W212/GLC…) / страница услуги (ТО/АКПП/двигатель) /
страница неисправности / инфо-статья. **Интент:** B2C коммерческий + информационный. **Приоритет:**
Яндекс + колдунщик Яндекс.Карт. Важно НЕ выдавать себя за официального дилера — «специализированный
сервис Mercedes-Benz».

**Суть.** Обязательные триплеты (специализация + Москва + услуги + Star Diagnosis/XENTRY + гарантия
+ сохранение гарантии производителя + цены ниже дилерских) есть почти у всех — на них не выехать.
Отстройка: (1) JSON-LD-разметка (у конкурентов почти нет) + (2) модельно-агрегатный инфо-контур
(болячки моделей/АКПП/двигателей/пневмоподвески/AdBlue).

**Обязательное ядро:**
- сервис → специализируется на → Mercedes-Benz | `AutoRepair.brand` (sameAs Wikidata Q36008)
- сервис → находится в → Москве (адрес+гео+метро) | `PostalAddress`/`geo`
- сервис → выполняет → ТО/диагностику/ремонт двигателя/АКПП/ходовой/электрики/кузова
- сервис → использует → Star Diagnosis/XENTRY | `Service.instrument`
- сервис → использует → оригинальные запчасти
- сервис → даёт гарантию → на работы/запчасти | `Offer.warranty`
- сервис → сохраняет → гарантию производителя
- услуга → выполняется для → модели W204/W212/GLC | страницы моделей
- ТО → стоит → от N ₽ | `Offer`

**Отстройка:** сертификат Росстандарта № РОСС RU.РТ01.М00057; партнёр программы MB «Независимый
специалист»; JSON-LD (AutoRepair+hasOfferCatalog+FAQPage+AggregateRating+sameAs); модель → болячка
→ узел → ремонт → цена с кодами ошибок.

**Модель/агрегат → типовая неисправность (инфо-контур):**
- АКПП 722.9 (7G) → плата проводимости/датчик VGS → коды P2767/P2768, толчки, аварийный режим →
  замена платы/гидроблока (SCN-кодирование обязательно); масло: ранние ~48 тыс. км, поздние «Plus» ~124 тыс.
- АКПП 725.0 (9G) → мехатроник/соленоиды → коды P060600 → толчки 1-2/2-3, аварийный режим
- АКПП 722.6 (5G) → электроплата/датчики оборотов → коды 12/108, 51/147 → течь по втулке разъёма
- M272/M273 → шестерня балансирного вала/промежуточная (плохой металл) → P0016/P0017 на 80–120 тыс. км
  (TSB S-B-03.30/08i; иск Seifi v. MBUSA) → замена вала+цепи+насоса
- M271 → растяжение цепи ГРМ, износ муфт → стук на холодную
- M276/M274 → натяжитель цепи, муфты-фазовращатели → треск на холодную
- OM651 → пьезофорсунки Delphi (P0201-0204), цепь ГРМ сзади, масляный насос (проворот вкладышей)
- Airmatic (W220/W221/W211/W212/GLE/GLC) → пневмобаллоны/компрессор → «CAR TOO LOW», аварийный режим
- AdBlue/SCR/BlueTec → P204F/P20EE/P2BA9 → кристаллизация мочевины, блокировка запуска → ремонт или
  программное отключение (аннулирует гарантию, повышает NOx — указывать честно)

**Сущности:** модели/кузова (C: W203/W204/W205/W206; E: W211/W212/W213; S: W220/W221/W222; ML/GLE:
W164/W166/W167; GLC: X253/X254; GL/GLS; A/B; CLS; G; V/Vito W447); АКПП (722.6/722.8/722.9/725.0);
двигатели (M271/M272/M273/M274/M276/M278; OM642/OM651/OM654/OM656); системы (Airmatic/ABC/AdBlue/
COMAND/ASSYST); услуги (ТО A/B, диагностика, ремонт двигателя/АКПП/ходовой/электрики/кузова, сход-
развал, замена масла/цепи ГРМ, отключение AdBlue, кодирование/прошивка); доверие (специализированный,
Росстандарт, XENTRY, оригинальные запчасти, сохранение гарантии). Внешние: Mercedes-Benz — Wikidata Q36008.

**Мета/структура:** главная (hero «специализированный сервис», блок доверия, каталог услуг/моделей);
страницы моделей (болячки кузова + FAQ + перелинковка на агрегаты); страницы услуг (с подстраницами
АКПП 722.6/722.9/725.0); кластер «неисправности» (лендинги по агрегатам с кодами ошибок → инфо-перехват).

**Разметка:** `AutoRepair` (подтип LocalBusiness) + `hasOfferCatalog`→`Offer` + `FAQPage` +
`BreadcrumbList` + `AggregateRating`/`Review` + `sameAs` (Яндекс.Карты, Wikidata Q36008, соцсети).
NAP-консистентность критична (сверять сайт ↔ Яндекс.Карты до символа).
