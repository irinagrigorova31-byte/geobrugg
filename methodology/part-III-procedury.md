# ЧАСТЬ III. РАБОЧИЕ ПРОЦЕДУРЫ

## 1. Активация и режимы

`/tripl` → запросить: **домен** (или «новый проект») + **список запросов** + **режим**:
1. Аудит страницы (URL/исходник) — по 5 слоям + целостность → диагноз и план.
2. Матрица триплетов — «сущности × предикаты × значения» + «обязательно/отстройка» + «куда внедрять».
3. Проектирование страницы — паспорт-абзац + TL;DR + пассажи + таблицы + JSON-LD.
4. Мета — title + description + og.
5. JSON-LD — блок разметки под страницу.
6. Карта сущностей ниши — кластеризация запросов в структуру URL (1 страница = 1 сущность).
7. GIST-аудит текста — QC готовой страницы/кластера по III-6 (заменимость, дубли, первая треть,
   FAQ-фильтр) + проверка серии по правилу III-7.

Без режима — начать с карты сущностей + матрицы триплетов. Любой сгенерированный текст перед
выдачей проходит режим 7 автоматически.

## 2. Сбор триплетов (вход: домен + запросы) — 5 источников

1. **Запросы** → разбор на сущности/интенты, кластеризация (кластер = сущность = страница).
2. **Расширение семантики** → подсказки, «люди спрашивают», Wordstat, отзывы → предикаты/вопросы.
3. **Реверс топа** → парсинг топ-10: их разметка (готовые триплеты), H2/H3 (подтемы), таблицы/числа,
   FAQ; entity-extraction (NL API) → карта сущностей. Частотность «атрибут → у скольких из топа»:
   8/10 = обязательно, 0/10 = отстройка.
4. **Граф знаний** → Wikidata Q-номера + офиц. источники → `sameAs` + канонические факты.
5. **Инвентаризация домена** → что бизнес вправе утверждать (БД, документы, УТП) + уникальные триплеты.

**Сборка — матрица:** строки — сущности, столбцы — предикаты, ячейки — значения; служебные колонки:
источник значения, частота у конкурентов, куда внедрён, **флаг «незаменимый узел»** (отстройка,
которую нельзя воспроизвести без данных бизнеса/редкой фактуры: собственный прайс, дефект узла с
кодами, дата-зависимый допуск, точка отказа). Пустая ячейка при высокой частоте = пробел
для добычи; заполненная при нулевой = отстройка. Матрица = ТЗ на текст + разметку + внешние подтверждения.
Флаг незаменимого узла питает правило III-7 и GIST-аудит III-6.

## 3. Инструменты (бесплатно / платно)

- **Разбор/кластеризация:** Google Sheets / LLM-разбор / Key Collector, Rush, Топвизор, Just-Magic.
- **Предикаты/вопросы:** Wordstat, подсказки, AlsoAsked, Arsenkin, Keys.so, Букварикс, отзывы/форумы.
- **Реверс топа:** Arsenkin (H1-H6), validator.schema.org (разметка конкурентов), Google NL API demo
  (5000/мес бесплатно) / TextRazor (500/день), Screaming Frog (до 500 URL), SERP API (XMLRiver, DataForSEO).
- **Граф:** Wikidata API/SPARQL, Google KG Search API, геосервисы (Яндекс.Карты, 2ГИС).
- **Автоматизация:** Python-скрипт (SERP API → extruct для JSON-LD → trafilatura+NL API → Wikidata → pandas xlsx).

## 4. Мета — ТЗ (кратко)

**Title:** 45–65 симв.; главная сущность в первых 40; [Сущность]+[тип/действие]+[гео]+[бренд];
запрещено — транслит/слаг, служебный префикс, брендовое самоназвание на коммерции, CAPS, эмодзи.
**Description:** 140–160 симв.; минимум одно число-факт (совпадает со страницей); 1–3 полных
предложения с пунктуацией; читается как самодостаточный ответ; запрещено — дубли, пустые эпитеты
без числа, обрыв на полуслове.
**og:** og:title без бренда; og:image 1200×630, латиница, https; og:type = article/product/website.
**Шаблонная генерация:** обработка вырожденных случаев (min=max → одно значение; пустое → ветка без
него; потерянные единицы). Приёмка на 10 случайных сущностях.

## 5. Валидация

validator.schema.org (полнота) → Rich Results Test (Google-сниппеты, битые картинки) →
Яндекс.Вебмастер (микроразметка). «Валидно» ≠ «правдиво» ≠ «сниппет покажут».
