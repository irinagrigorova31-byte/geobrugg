# Бэклинки от оператора (OFF-SITE) — заполнить

Ссылки на НАШ сайт, которые должны нести внешние размещения (off-site-ветка). Заполняет **оператор**.
Читает `external-tz-writer` (кладёт в блок ПОЛИТИКА БЭКЛИНКА каждого off-site-ТЗ), вшивает
`external-copywriter`, проверяет `external-gist-auditor`.

Правила:
- **Ссылки — follow** (наш стандарт). Если площадка принудительно ставит nofollow на все внешние
  ссылки — это ограничение площадки (агент пометит), мы его не переопределяем.
- **Анкор** — как задан здесь (обычно каноническое имя сущности из `data/entities.md`, не
  коммерческий ключ). Один анкор на одну цель по возможности.
- Одна строка = один бэклинк под конкретное размещение. Если под размещение бэклинка нет — оставь
  пусто, агент задаст вопрос, но ссылку без цели не поставит.
- Целевой URL — реальная страница нашего сайта (обычно та, чей citation-gap закрываем).

| Целевой URL (наш сайт) | Анкор |
|---|---|
| https://example.com/target-page | каноническое имя сущности |
|  |  |
